# 🎮 Jogo da Velha (Tic-Tac-Toe)

Projeto desenvolvido para a disciplina de Front-End, utilizando HTML, CSS e JavaScript.

## 💡 Sobre o projeto

O Jogo da Velha permite que dois jogadores se enfrentem em tempo real, alternando entre "X" e "O" até que um vença ou o jogo termine empatado.

## 🧪 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (puro)  
- Responsividade com Media Queries

## 🚀 Funcionalidades

✅ Tabuleiro de 3x3 interativo  
✅ Alternância entre os jogadores (X e O)  
✅ Verificação automática de vitória ou empate  
✅ Placar dinâmico para acompanhar pontuação  
✅ Botão para reiniciar apenas a rodada  
✅ Botão para zerar pontuação completa    
✅ Interface bonita e responsiva para celular e computador 

## 🖼️ Layout Responsivo

O projeto foi desenvolvido com foco em uma interface moderna e adaptável a diferentes tamanhos de tela (mobile, tablet e desktop).

## 🧠 O que aprendi

- Manipulação do DOM com JavaScript
- Uso de arrays para lógica de jogo
- Organização de código e boas práticas
- Animações e sons para melhorar a experiência do usuário

## 🚀 Como rodar

1. Baixe o projeto
2. Abra o arquivo "index.html" em um navegador
3. Divirta-se!
